Review notes

  • Use exact requested name unless corrected.
  • All 37 patient-information requirement groups listed by the user are now included in the nursing template. Only patient name, address, birth date and sex remain outside the form.
  • Patient-profile integration is outside this change. These fields save with the care-plan assessment and do not automatically synchronize with Client, insurance, intake, directives or eMAR records.
  • Only nursing screenshots 1–8 are in scope; 9–10 are unrelated asset-picker screenshots.
  • Final supplied page is included: discipline goals and achievement dates, discharge planning, rehabilitation potential and staff completion/signature.
  • Risk wording and point values are transcribed from the supplied form, not independently clinically validated.
  • All fields are optional because the source does not identify required fields and many sections may not apply.
  • TABLE, TEXT_DISPLAY and CALCULATED_SCORE are avoided because the current care-plan renderer lacks implementations.
  • String options are required by the current top-level care-plan renderer. Its existing choice editor expects object options; this pre-existing compatibility issue should be fixed before editing choices in the builder.
